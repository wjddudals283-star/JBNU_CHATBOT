# 총학 인스타 공지 — 조사 결과와 토큰 발급 절차

## 왜 하는가

총학 공지는 수요 6위(32.4%)인데 **우리가 못 닿는 유일한 원천**이었다.
학교 홈페이지 교내공지 게시판을 세어 봤더니 총학 게시물이 **0건**이다.
총학은 인스타에만 올린다.

## 캡션이 값어치가 있나 — 있다

실제 표본(2026 학문체 댄스제 모집)을 자족성 판정기에 걸었다.

```
캡션 전체        자족 · 이름:값 쌍
6줄 전부 자족    모집 기간 / 모집 대상 / 모집 방법 / 참가비 / 본선 일시
답값             DATE 3건 · MONEY 2건 · PERIOD 1건
```

`이름만 있는 조각`이 아니라 **이름 + 값**이 다 있다. 우리 판정기를 그대로 통과한다.
"자세한 내용은 카드뉴스 참고" 류였으면 값이 없었을 텐데 그렇지 않았다.

★ **OCR 이 필요 없다.** 캡션만 쓴다. 이미지는 안 읽는다.

## 구조 — `notice.search` 와 같다

```
공지 검색   제목 + 게시일 + 링크          본문은 안 읽는다
인스타      캡션 앞부분 + 날짜 + 링크      이미지는 안 읽는다
```

요약하지 않는다. 캡션을 그대로 옮기고 길면 자르되 **잘랐다는 사실을 표시**한다.
학생은 `permalink` 로 원문을 확인할 수 있다 — 우리 인용 규칙 그대로다.

## 스크래핑은 안 한다

로그인 상태에서도 그리드 재로딩이 3회 연속 실패했다. 인스타가 조이고 있고,
**그건 우회할 선이 아니다.** Graph API 로 간다 —
총학이 계정 소유자이므로 자기 콘텐츠를 API 로 읽는 것은 정당한 접근이다.

# 총학이 할 일 (화면 순서)

⚠️ **Meta 는 화면 이름과 메뉴 위치를 자주 바꾼다.** 아래 이름이 안 보이면
비슷한 뜻의 버튼을 찾으면 된다. 순서와 목적은 잘 안 바뀐다.

## 0단계 — 계정 종류 확인 (먼저 이것부터)

인스타 앱 → `프로필` → 우측 상단 `☰` → `설정 및 개인정보` →
`계정 유형 및 도구` 에서 지금이 무엇인지 본다.

```
개인 계정             → 전환 필요
프로페셔널(비즈니스)    → 그대로 진행 가능
프로페셔널(크리에이터)  → 그대로 진행 가능
```

개인 계정이면 `프로페셔널 계정으로 전환` 을 누른다.
카테고리는 `교육` 이나 `단체` 중 아무거나 골라도 된다.

★ 이 단계에서 막히면 나머지가 다 안 된다. 여기부터 확인해 주세요.

## 1단계 — Meta 개발자 계정 만들기

1. `developers.facebook.com` 접속
2. 우측 상단 `시작하기` (또는 `로그인`) → 페이스북 계정으로 로그인
3. 개발자 등록 — 전화번호 인증을 요구할 수 있다

★ 총학 공용 페이스북 계정이 있으면 그걸 쓰는 게 좋다.
  개인 계정으로 만들면 나중에 인수인계가 안 된다. **59대에게 넘겨야 한다.**

## 2단계 — 앱 만들기

1. `내 앱` → `앱 만들기`
2. 앱 용도: `비즈니스` 계열을 고른다
3. 앱 이름: `전북대 총학 챗봇` 같은 식별 가능한 이름

## 3단계 — Instagram 제품 추가

앱 대시보드에서 `제품 추가` → **Instagram** → `설정`

여기서 두 갈래가 있다. **어느 쪽이 보이는지 알려주시면** 그다음을 정확히 안내하겠다.

```
A. Instagram API with Instagram Login      페이스북 페이지 연결이 필요 없다   ← 있으면 이쪽
B. Instagram API with Facebook Login       인스타를 페이스북 페이지에 연결해야 한다
```

B 만 보이면 페이스북 페이지를 하나 만들어 인스타 계정과 연결해야 한다
(인스타 앱 → 설정 → `연결된 계정`).

## 4단계 — 권한

필요한 권한은 **읽기 전용 두 개뿐**이다. 그 이상은 신청하지 않는다.

```
instagram_business_basic   (또는 구버전 instagram_basic)
   → 계정 정보와 미디어 목록 읽기
```

★ 게시·삭제·댓글 권한은 **요청하지 않는다.** 우리는 읽기만 한다.
  권한을 넓게 받아두면 사고 났을 때 피해 범위가 넓어진다.

## 5단계 — 토큰 받기

`Instagram > API 설정` 화면에 토큰 생성 버튼이 있다.
누르면 인스타 계정 로그인/동의 창이 뜨고, 동의하면 **액세스 토큰** 문자열이 나온다.

```
받은 토큰을 그대로 저에게 보내지 마세요.
Render 환경변수에 직접 넣으시면 됩니다 —  INSTAGRAM_TOKEN
```

★ 토큰은 비밀번호와 같다. 채팅·문서·깃허브에 붙여넣지 않는다.
  이 저장소는 Public 이고, 한 번 커밋되면 지워도 히스토리에 남는다.

## 6단계 — 계정 ID 확인

같은 화면에 `Instagram 사용자 ID` 또는 비슷한 숫자가 있다. 그 숫자도 필요하다
(토큰과 달리 비밀이 아니므로 알려주셔도 된다).

# 우리가 만들 것

## 가져올 필드

```
caption      공지 본문
permalink    원문 링크 — 학생이 확인할 수 있어야 한다
timestamp    게시 시각
media_type   IMAGE / VIDEO / CAROUSEL_ALBUM
```

## 범위 — 58대 임기분만

게시물 2,860개를 전부 가져오지 않는다. `timestamp` 로 자른다.
지난 집행부 공지를 지금 공지처럼 내보내면 그게 **낡은 인용**이다 —
오늘 OASIS 건에서 겪은 것과 같은 실패다.

## ★ 토큰 수명이 설계 문제다

장기 토큰도 **60일**이면 만료된다. 갱신을 사람이 기억해야 하면 그건 설계가 아니다.

```
자동 갱신    스케줄러가 주기적으로 refresh 를 호출한다
만료 경보    /admin/status 에 남은 날짜를 낸다 — 30일 전부터 눈에 띄게
실패 처리    토큰이 죽으면 '인스타 공지는 지금 확인 못 한다' 고 말한다
             ★ 조용히 옛 데이터를 내보내지 않는다
```

세 번째가 제일 중요하다. 오늘 우리가 겪은 게 정확히 그것이다.

## 개인정보 판단 (기록)

```
결정      캡션에 든 이메일·계좌·연락처를 마스킹하지 않는다
근거      이미 공개 계정의 공개 게시물이고, 총학이 학생에게 알리려고 올린 정보다
결정자    총학생회장
결정일    2026-08-13
```

★ 나중에 문제가 되면 **언제 누가 정했는지** 이 줄을 보면 된다.
  다시 판단할 일이 생기면 이 결정을 바꾸고 날짜를 새로 적는다.
