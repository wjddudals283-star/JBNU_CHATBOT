# 총학 공지·행사 시트 (T4)

인스타에 공지를 올릴 때 **시트에도 한 줄 붙여넣으면** 챗봇이 그대로 답합니다.

```
시트    전북대 총학 챗봇 · 총학 공지·행사 입력
계정    jbnuch58@gmail.com
칸      게시일 | 제목 | 내용 | 인스타링크 | 마감일 | 작성국
```

---

## 왜 인스타 API 를 안 쓰나

```
앱 심사          Meta 승인 절차가 필요하다
토큰 60일 만료    두 달마다 사람이 기억해서 갱신해야 한다
페이스북 페이지    인스타를 페이지에 연결해야 하는 경우가 있다
```

학식 자료 백필에서 이미 배웠습니다 — **사람이 기억하는 구조는 학기 중에 집니다.**
실제로 백필 하루를 걸렀습니다. 개강하면 총학이 제일 바쁠 때입니다.

시트는 이미 쓰는 도구고, 인스타에 올릴 때 한 번 더 붙여넣으면 끝납니다.
관리할 비밀도 안 늘어납니다.

# 쓰는 법

## 새 공지를 올릴 때

인스타에 올린 뒤, 시트에 한 줄 추가합니다.

| 칸 | 넣는 것 | 비고 |
|---|---|---|
| 게시일 | `2026-08-25` 또는 `8/25` | 연도를 안 쓰면 올해로 봅니다 |
| 제목 | 학생이 검색할 만한 이름 | ★ **여기가 검색 대상입니다** |
| 내용 | **인스타 캡션을 그대로 복사** | 줄바꿈 그대로 두세요 |
| 인스타링크 | 그 게시물 주소 | 학생이 원문을 볼 수 있게 |
| 마감일 | `2026-08-25` | ★ **지나면 자동으로 안 나갑니다** |
| 작성국 | 문화국 · 복지국 등 | |

## ★ 캡션은 줄이지 마세요

우리가 요약하지 않습니다. **그대로 내보냅니다.**

8/14 에 실제 캡션을 재봤더니 이랬습니다.

```
모집 기간 · 모집 대상 · 모집 방법 · 참가비 · 본선 일시
→ 여섯 줄이 전부 '이름 : 값' 으로 자족적
```

줄이면 그 값들이 사라집니다. 길면 챗봇이 자르고 **"뒷부분이 있어요"** 라고
표시한 뒤 인스타 링크로 보냅니다.

## ★ 마감일을 꼭 넣어 주세요

마감일이 지나면 그 글은 **자동으로 후보에서 빠집니다.**

> 9월에 "8월 25일까지 신청하세요" 가 나가면 크롤 오답보다 나쁩니다.
> 총학이 직접 넣은 것이라 학생이 더 믿기 때문입니다.

마감이 **없는** 안내(사무실 이전, 상시 접수)는 마감일 칸을 **비워** 두세요.
비워 두면 계속 나갑니다.

★ `9월 초`, `미정` 처럼 날짜가 아닌 말을 쓰면 **그 줄이 통째로 안 나갑니다.**
  우리가 `9월 1일` 로 추측해서 바꾸면, 총학이 쓰지 않은 마감일을
  우리가 만들어낸 것이 됩니다. 정확한 날짜를 모르면 비워 두세요.

## 지운 글

시트에서 줄을 지우면 챗봇에서도 사라집니다.
잘못 올렸을 때 되돌릴 수 있어야 하니까요.

# 시트에 넣지 말아야 할 것

이 시트는 **'웹에 게시' 로 공개**되어 있습니다 (그래야 챗봇이 읽습니다).
주소를 아는 사람은 누구나 읽을 수 있습니다.

```
넣어도 되는 것    인스타에 이미 올라간 공지 · 작성국
넣으면 안 되는 것  학생 개인정보 · 내부 논의 · 미공개 계획 · 연락처 명부
```

★ 인스타에 올린 것과 같은 내용만 넣으면 안전합니다.
  이미 공개된 것을 한 번 더 옮기는 것뿐입니다.

# 학생에게 어떻게 나가나

## 공지가 있을 때

```
[2026 학문체 댄스제 모집]

모집 기간 : 8/13(수) ~ 8/25(월) 23:59
모집 대상 : 전북대 재학생 누구나
참가비 : 팀당 10,000원

마감 8/25 · 문화국 · 8/13 게시
https://instagram.com/p/AAA

총학생회가 직접 올린 공지예요.
```

## 못 가져왔을 때

```
최근 총학 공지를 아직 못 가져왔어요.
총학 인스타를 확인해 주세요.
[총학 인스타 열기]
```

★ **"공지가 없어요" 라고 하지 않습니다.**
  진짜로 공지가 없는 건지 우리가 시트를 못 읽은 건지 구별할 수 없기 때문입니다.
  구별 못 하는 걸 구별한 척하는 게 우리가 제일 조심하는 것입니다.

## 학생은 '총학 공지' 라고 안 칩니다

`댄스제` 라고 칩니다. 그래서 **제목**으로도 찾습니다 —
제목을 학생이 부를 만한 이름으로 지어 주세요.

```
좋음   2026 학문체 댄스제 모집
아쉬움  8월 셋째 주 공지
```

# 켜는 법 (한 번만)

## 1. 시트를 웹에 게시

1. 시트 열기 → `파일` → `공유` → **`웹에 게시`**
2. 게시할 시트: **해당 탭 하나만** (전체 문서 아님)
3. 형식: **`쉼표로 구분된 값(.csv)`**
4. `게시` → 나오는 주소를 복사

## 2. Render 에 주소 넣기

1. https://dashboard.render.com → `jbnu-chatbot` → `Environment`
2. `Add Environment Variable`

```
Key    COUNCIL_SHEET_CSV
Value  (복사한 주소)
```

3. 저장하면 자동 배포됩니다

★ 이 주소는 비밀이 아닙니다 (공개 게시한 것이라). 다만 저장소에는 안 넣습니다 —
  주소가 바뀌어도 배포 없이 고칠 수 있어야 하기 때문입니다.

## 3. 확인

```
07:00 · 12:00 · 17:00 · 21:00   하루 네 번 읽습니다
```

`/admin/status` 의 `sources` 에서 `council_sheet` 의 마지막 성공을 볼 수 있습니다.
하루 넘게 못 읽으면 학생에게 **"못 가져왔어요"** 가 나갑니다 —
틀린 공지는 안 나갑니다.
