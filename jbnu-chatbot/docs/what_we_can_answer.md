> # ★ 13% 는 "우리가 아는 게 13%" 지 "학생이 받는 게 나빠졌다" 가 아니다
>
> **배포 조건은 안 움직였다.** `확신하고 틀린 것 0건` 그대로다.
> 학생이 받는 답은 8/17 과 8/18 이 **똑같다** — 바뀐 것은 자뿐이다.
>
> ```
> 85%  →  37%   자를 고쳤다 (인용문에서 찾나 · 경로에서 찾나)
> 38%  →  13%   자를 고쳤다 (문서를 찾았나 · 맞는 문서인가)
> ```
>
> 두 번 다 **숫자가 내려간 게 아니라 원래 그 상태였다.**
> 34건은 답을 냈지만 그게 맞는 문서인지 사람이 확인한 적이 없다.
> 확인 안 한 걸 통과로 세는 것이 거짓말이고, 그 거짓말을 없앤 숫자가 13% 다.
>
> ★ 집행부에 보일 때 이 문장이 같이 가야 한다. 안 그러면
>   "챗봇이 나빠졌다" 로 읽힌다. 나빠진 건 없다 — 보이게 됐을 뿐이다.

# ② 표 렌더링 — (a) 를 다시 재고 또 멈췄다 (2026-08-17)

## 결론: (a) 의 사정거리가 **46문항 기준 0/5** 다

전체 코퍼스로는 그릴 수 있어 보였다.

```

  헤더 셀 수 = 행 셀 수      6,579  (21.0%)   ← 그릴 수 있다
  열 수 다름               24,270  (77.5%)
  헤더 못 찾음                485  ( 1.5%)
```

그런데 **실제 답에 나오는 표**로 재니 0 이다.

```
46문항 중 FOUND 30건 · 그중 인용이 표인 것 5건
  전부 kind='table' (표 전체)     → 헤더/행 셀 = 1/15, 1/21, 1/43 …
  kind='table_row' 는 0건
```

★ **인용은 자족성 승격 때문에 부모 블록(표 전체)으로 올라간다.**
  행 단위(table_row)는 인용에 안 나온다. 그래서 행 단위로 그리는 규칙은
  실제 답을 하나도 못 건드린다.

  이건 전에 표 전치를 되돌릴 때 적은 결론과 같다 —
  "필요하면서 가능한 건이 0건". 자를 바꿔도 그 결론이 유지된다.

### 재는 자가 두 번 틀렸다 (같은 턴에)

1. `연혁` 을 '지난 명단' 에 넣었다. **연혁을 물으면 연혁 페이지가 정답이다.**
   `간호대학 연혁` 이 오답으로 세어졌다.
2. `전임교수` 를 '지난 사람' 으로 셌다. **전임(專任)은 현직 정교수다.**
   전(前)임으로 읽었다. 이것 때문에 6건이 2건으로 정정됐다 — 실제의 3배로
   알 뻔했다.

둘 다 낱말 뜻을 내가 정하고 코퍼스에 물어보지 않아서 났다.

### 검수 시트의 ❗ 가 4건 → 0건이 됐다. **안심 신호가 아니다**

❗ 는 '질문 낱말이 제목·경로에 하나도 없음' 을 잡는 신호였다.

## 곁가지 — 페이지는 받았는데 내용이 안 들어온 것 (2026-08-18)

`certificate.do`(증명서발급)를 보다 나온 것이라 따로 센다. **동점 문제가 아니다.**

    certificate.do   파싱 ok · 섹션 2 · 잎 1 · 본문 218자 · 가지친 노드 17
    → 실패가 아니다. 그 페이지에 원래 글이 거의 없다(내용이 하위 링크에 있다).

200 으로 받아온 **6,984개**의 잎 분포:

    잎 0개    1,199개 (17.2%)   empty 984 · parse_error 215
    잎 1개    1,267개 (18.1%)
    잎 2~4개  1,248개 (17.9%)
    잎 5개 이상 3,270개 (46.8%)

    잎 0개인데 본문 글자 200 이상 →   0개   ← 글이 있는데 못 쪼갠 건 없다
    잎 0~1개인데 본문 글자 200 이상 → 138개  ← 파서가 한 덩어리로 둔 자리

**`parse_error` 215개가 진짜 '못 긁음'이다.** 나머지는 원래 빈 페이지거나
(회원가입·목록 페이지) 한 덩어리로 남은 것이다. 개강 뒤 (A) 파서 작업 때 같이 본다.
