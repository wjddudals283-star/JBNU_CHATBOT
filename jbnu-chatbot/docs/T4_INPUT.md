# 홈페이지에 없는 것을 넣는 법 (T4)

크롤로는 영영 못 채우는 것이 있다.
`학점포기`, `수강신청 정정기간`, `기숙사 통금` — 학교 홈페이지에 안 적혀 있다.
학생은 묻는데 우리는 답할 자료가 없다. **총학이 직접 확인해서 넣는다.**

파일 하나만 고치면 된다: `config/manual_answers.yaml`

---

## 넣는 순서

1. **전화해서 확인한다.** 학사과·생활관 행정실 등
2. `config/manual_answers.yaml` 에서 해당 항목을 찾아 채운다

```yaml
  - key: 학점포기
    ask: [학점포기, 학점 포기, 학점포기제]      # 학생이 이렇게 물으면
    answer: |
      전북대는 학점포기 제도를 운영하지 않습니다.
      재수강으로 성적을 정정할 수 있고, 재수강 시 원래 성적은 남지 않습니다.
    source: 학사과 유선 확인                    # 어디에 물었나
    verified_by: 사무국장                       # 직책. 실명 금지
    verified_at: 2026-08-11                     # 확인한 날
    valid_to: 2027-02-28                        # 언제까지 믿을 수 있나
    enabled: true                               # 확인 끝나면 true
```

3. 커밋하고 배포한다

---

## 규칙 (안전 연락처와 같다)

| 규칙 | 왜 |
|---|---|
| **확인한 것만 넣는다** | 들은 말·추측·"아마도" 는 답이 아니다 |
| `verified_by` 는 **직책** | 공개 저장소에 실명이 남으면 안 된다 |
| `valid_to` 를 **반드시** 적는다 | 학사 제도는 바뀐다. 지난 답을 계속 내보내는 것이 모르는 것보다 위험하다 |
| 확인 전에는 `enabled: false` | 틀만 채운 상태가 학생에게 나가면 안 된다 |

**하나라도 비면 그 항목은 나가지 않는다.** 확인자·확인일·만료일·본문 중
어느 하나라도 없으면 챗봇은 그냥 검색으로 넘어간다.
만료일이 지나면 스스로 꺼진다.

---

## 답이 이렇게 나간다

```
전북대는 학점포기 제도를 운영하지 않습니다.
재수강으로 성적을 정정할 수 있고, 재수강 시 원래 성적은 남지 않습니다.

📌 총학생회가 학사과 유선 확인한 내용이에요 (2026-08-11 확인)
```

홈페이지 링크가 없으므로 **어디에 물어 확인했는지**를 대신 밝힌다.
학생이 검증할 수 있어야 한다 — 검증할 수 없는 답은 믿어달라는 요구다.

---

## 상태 확인

```
GET /admin/manual        (X-Skill-Token 필요)
```

```json
{ "total": 3, "live": 1, "expired": 1, "unverified": 1,
  "expiring_soon": ["기숙사_통금"] }
```

- `unverified` — 틀만 있고 아직 확인 안 된 것
- `expired` — 만료돼서 지금 안 나가는 것
- `expiring_soon` — **30일 안에 만료될 것**. 만료된 뒤에 아는 것은 늦다

학기 시작 전에 한 번씩 열어보면 된다.
