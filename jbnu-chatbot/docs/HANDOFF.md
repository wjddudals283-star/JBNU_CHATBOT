## 0. 한 줄

> 학교 정보를 **지어내지 않고** 답하는 카톡 챗봇.
> 핵심 기능은 "모르는 것을 모른다고 말하는 것"이다.

실시간 경로에 **생성 모델이 없다.** 답변은 전부 템플릿(f-string)이고,
값이 없으면 문장을 만들지 않고 "모른다" 분기로 간다.
검색은 문서를 찾아 **원문 그대로 인용**한다. 요약하지 않는다.

## 2. 설계 — 3계층

```
원천(Source)  원문 스냅샷을 그대로 저장
   ↓ 게이트  스키마 → 도메인 규칙 → 이상치 → 정합 앵커 → 교차검증
사실(Fact)    출처·관측시각·신뢰도를 달고 저장
   ↓ 템플릿 (생성 모델 없음)
답변(Answer)
```

### 티어
`T1` 자동 크롤 · `T2` 반정적 · `T3` 문서 · `T4` 사람이 직접 입력

### 답변 분기 (식단 기준)
- **A** 사실 있고 신선함 → 보여준다
- **B** 관측된 미운영 → "안 해요" + 근거(운영시간)
- **C-1** 운영은 하는데 메뉴 미게시
- **C-2** 모름
  B와 C를 뭉치면 "안 하는 것"과 "모르는 것"이 구별되지 않는다.

## 5. 이 프로젝트의 규칙 (가장 중요 — 이걸 모르면 같은 실수를 반복한다)

### 정확성
- **모르는 것을 모른다고 말하는 것이 기능이다**
- **긍정 단정에는 높은 근거를, 부정·유보에는 낮은 근거를 요구한다**
- **조인은 추론이다. 추론으로 채운 값은 사실이 아니다** (가격 매칭은 정확 일치만)
- **요약하지 않는다.** 규정 요약은 특히 위험하다. 길면 앞부분 + 전문 링크, 그리고 **잘랐다고 말한다**
- **답에 질문 대상을 넣는다.** 답에 대상이 없으면 학생이 "내 질문에 답한 게 맞나"를 판단할 수 없고, 판단할 수 없는 답은 틀린 답과 구별되지 않는다
- **애매하면 고르지 않는다.** 찍는 것은 추론이다

### 관측
- **저장하는 건 관측, 결합은 질의 계층에서 매번 다시 한다**
- **부정도 관측이다. 행으로 남긴다** (미운영을 '없음'이 아니라 `is_closed` 행으로)
- **관측의 부재는 충돌이 아니다.** 침묵과 진술은 서로 모순하지 않는다
- **설정은 선언이지 관측이 아니다**
- **표본 두세 개로 종류를 세는 건 관측이 아니라 추측이다** ← 전수 조사 원칙
- **비교는 정규화본으로, 저장은 원문으로**

### 시간
- **이력을 쌓는 테이블은 식별자에 시점이 있어야 한다**
- **크롤 주기 ≤ 신선도 임계 ÷ 2** (야간 간격이 항상 최대치다)
- **시계는 한 군데서만 읽는다** (`server.now_kst()`)

### 운영
- **우리는 손님이다** — 요청 간격 준수, 호스트 번갈아 돌기, 같은 페이지 두 번 안 두드리기
- **침묵이 가장 위험하다** — 할 일이 없어도 로그를 남긴다
- **조용한 절단 금지** — 자르면 몇 개를 잘랐는지 보고한다
- **지우는 쪽이 되돌리기 어렵다** — 근거가 부족하면 지우지 않는다
- **하드코딩하지 않는다** — 노이즈는 관측(반복 출현)으로 가려낸다
- **한 번 커밋된 시크릿은 히스토리에 남는다** — 올리기 전에 거르는 게 유일한 방법

### '없다'의 갈래 (뭉치면 고칠 수 없다)
```
페이지:  ok / empty(본문없음) / board(게시판) / parse_error / fetch_error / blocked / not_attempted
검색:    FOUND / AMBIGUOUS / NOT_FOUND(찾아봤다) / NO_DATA(안 긁었다) / NO_QUERY / PERSONAL
```

## 6. 오늘 발견한 결함 패턴 (반복됨 — 주의)

| 패턴 | 실제 사례 |
|---|---|
| **확인 안 하고 그럴듯한 걸 만들어냄** | `h3/h4` 마크업 가정 / "본부는 CMS 하나" / 존재하지 않는 URL 4건 (기숙사는 `dorm`이 아니라 `likehome`, 도서관은 `lib`가 아니라 `dl`) |
| **환경 의존** | 픽스처(바이트 동일) / IP 위치(국내 200, 해외 403) / **자정 넘어 테스트 3개 조용히 깨짐** / 미래 `fetched_at` |
| **무거운 작업이 플래그에 묶임** | 스모크 → 테스트가 실사이트 두드림. **똑같은 결함이 job에서 재발** (7,000회 요청, 스위트 멈춤) |
| **조용한 절단** | 후보 400개를 아무 순서로 자름 → 6만 섹션에서 **정답이 잘려나감** |
| **순환 논리** | 잎의 경로 마지막 칸이 잎 텍스트 → "내 제목에 내 말이 있다" |
| **측정 도구가 틀림** | 공대 "본문 52,000자"는 전부 `<script>` 안. 실제 24자 |

→ **재기 전에는 종류를 세지 않는다**를 원칙으로 유지한다.

## 9. 실행 방법

```bash
python -m pytest -q                              # 테스트 378개
python -m crawler.pages_run --db data/jbnu.db    # 안내 수집 (~50분)
python -m crawler.notices_run --db data/jbnu.db  # 공지 갱신 (~5분)
python tools/answerability_report.py --db data/jbnu.db   # 정확도 측정
```

관리 엔드포인트 (전부 `X-Skill-Token` 필요)
```
GET /admin/coverage    페이지 커버리지 + 못 읽는 이유
GET /admin/manual      T4 상태 (만료·미확인·만료 임박 30일)
GET /admin/freshness   원천별 마지막 성공 + stale
GET /admin/status      스케줄러 상태
GET /admin/blocks      블록 매핑 + 매핑 안 된 블록
```

배포: Render Starter, singapore, 디스크 `/var/data`.
`RUN_SCHEDULER=1` 이 있어야 야간 수집이 돈다.
생협은 해외 IP 차단이라 노트북(한국 IP) 백필 → `POST /admin/ingest` (docs/BACKFILL.md)

## 11. 이 프로젝트를 이어받을 때

1. **`docs/what_we_can_answer.md` 를 먼저 읽는다** — 무엇을 줄 수 있는지가 거기 있다
2. **숫자를 믿기 전에 재본다** — `tools/answerability_report.py`
3. **마크업을 상상하지 않는다** — 열어보고 세본다
4. **틀린 것과 놓친 것을 같은 무게로 세지 않는다**
   놓치면 학생이 다른 데를 찾는다. 틀리면 잘못된 곳으로 간다.
   `확신하고 틀린 것 0건` 이 배포 조건이다
