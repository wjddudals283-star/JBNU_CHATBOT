# career.jbnu.ac.kr — 크롤 추가는 접었다 (2026-08-14)

## 왜 봤나

`취업·비교과` 버튼이 **전화번호 표**를 내놓았다. 대표가 원한 건
"지금 신청할 수 있는 것" 의 목록이다.

코퍼스를 재보니 career.jbnu.ac.kr 의 **공지가 0건**이었다.
페이지는 200섹션 들어와 있다 — 그래서 전화번호 표(상담실 안내)가 나갔다.

대표 가설: "취업 전담 사이트인데 공지가 0건인 건 우리가 안 긁어서지
없어서가 아닐 가능성이 높다."

## 재봤다 — 가설이 틀렸다

`career/index.do` 에서 subview 링크 43개를 뽑아 **전부** 두드렸다.

```
로그인 필요        25개
일반 안내 페이지    18개   ← 이미 우리가 긁고 있는 것 (부서소개·상담실)
게시판 항목 나온 곳   0개
```

알맹이는 전부 로그인 뒤에 있다.

```
채용설명회 일정   →  "알립니다. 로그인 후 이용가능합니다."   (6,972B)
취업진로프로그램  →  같음
프로그램        →  같음
해외채용정보     →  73KB 인데 표가 없다 (본문이 메뉴뿐)
```

★ **안 긁은 게 아니라 못 긁는다.** 로그인 우회는 우리가 넘을 선이 아니다
  (인스타 스크래핑을 접은 것과 같은 판단이다).

## 그래서 어디서 가져오나

이미 갖고 있다. 학과·본부 게시판에 **891건**이 있다.

```
본부 www.jbnu.ac.kr   156건   교내공지 · 교내채용 · 공모/스터디 · 특강&세미나
학과 게시판           239종   molb 취업공지 · english 취업정보 · res 대외활동/취업게시판 …
총학 시트 (T4)        분류=취업·비교과 를 사람이 적은 것만
```

★ 못 집던 이유는 크롤이 아니라 **검색**이었다.
  `취업` 이 career.jbnu.ac.kr 사이트 별칭이라 공지 검색이 그 사이트로 좁혀졌고,
  거기 공지가 0건이라 제목에 `취업` 이 든 139건을 **0건으로 만들었다.**
  (2026-08-14 수정 — 공지가 없는 사이트로는 좁히지 않는다)

## 다시 볼 일이 생긴다면

```
총학 계정으로 로그인해서 긁는다   ← 계정 공유·약관 문제. 권하지 않는다
취업진로지원과에 자료 요청        ← 사람 경로. 시트에 넣으면 T4 가 된다
로그인 없이 보이는 RSS/공개 목록   ← 있는지 다시 재봐야 한다
```

두 번째가 현실적이다. 총학이 이미 시트를 쓰고 있으므로 추가 도구가 안 든다.
