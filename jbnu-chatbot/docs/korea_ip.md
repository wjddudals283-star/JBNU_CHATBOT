# 한국 IP 에서 도는 자리 — 조사 결과 (2026-08-14)

## 왜 필요한가

생협 식단 API 가 **해외 IP 에서 막힌다.** Render 는 싱가포르라 못 가져온다.
지금 우회책은 노트북(한국 IP)에서 주 2회 수동 백필이다.

그런데 대표가 이 프로젝트에 처음 건 조건이 이거였다.

```
자동 크롤로 사람이 관리하지 않아도 계속 업데이트
```

주 2회 수동 백필은 그 원칙을 정면으로 깬다. 8/13(목) 백필이 이미 안 돌았다.
개강하면 총학이 제일 바쁠 때고, 그때 더 안 돈다.

★ **다만 이 문서는 조사다.** 개강 18일 전에 새 인프라를 세우는 게 맞는지는
  대표가 정한다. 여기 있는 건 정하는 데 필요한 사실뿐이다.

## 오라클 클라우드 — 춘천 리전

### ★ 확인된 제약 하나가 결정적이다

Oracle 공식 문서에 이렇게 적혀 있다.

> OCI Ampere A1 Compute 인스턴스는 **South Korea North (Chuncheon) 을 제외한**
> 모든 가용 도메인에서 만들 수 있다.

즉 **춘천에서는 Ampere A1(ARM) 을 못 만든다.** 무료 등급의 좋은 쪽이 그것이다.

```
VM.Standard.A1.Flex   ARM · 2 OCPU · 12GB      ← 춘천 불가
VM.Standard.E2.1.Micro AMD · 1/8 OCPU · 1GB    ← 별도 제외 표기 없음
```

그리고 **Always Free 인스턴스는 홈 리전에만 만들 수 있다.**
춘천을 쓰려면 계정을 만들 때 홈 리전을 춘천으로 잡아야 하고,
홈 리전은 나중에 못 바꾼다.

### 그래서 춘천에서 쓸 수 있는 건

```
E2.1.Micro 2대   1/8 OCPU · 메모리 1GB
```

우리가 시킬 일은 **하루 세 번 HTTP 요청 하나 보내고 서버로 밀어넣기**다.
`crawler/push.py` 가 이미 그 일을 한다. 1GB 로 충분하다 —
파싱은 우리 서버가 다시 하므로 이쪽은 원문 바이트를 옮기기만 한다.

### 2026-06-15 변경

Ampere A1 무료 한도가 절반으로 줄었다(4→2 OCPU, 24→12GB).
우리에게는 상관없다. A1 을 애초에 못 쓴다.

## 정하기 전에 알아야 할 것

### ① 무료가 영구인가

Oracle 은 'Always Free' 라고 부르지만, 한도와 정책을 **예고 없이 바꾼 전례**가 있다
(6월 A1 반토막이 공지 없이 됐다). 영구 무료를 설계의 전제로 삼지 않는 게 맞다.

★ 그래서 이 경로는 **끊겨도 우리가 조용히 안 틀리는** 구조여야 한다.
  오늘 넣은 신선도 문안이 정확히 그 안전망이다 —
  밀어넣기가 멈추면 학생은 "이건 8/12 자료예요" 를 본다.

### ② 계정 만들기에 카드가 필요하다

Always Free 만 쓸 거라도 가입에 신용/체크카드 확인이 필요하다.
**총학 공용으로 만들 수 있는지**가 실무 문제다 — 개인 카드로 만들면
59대에게 인수인계가 안 된다. 인스타 개발자 계정에서 겪은 것과 같은 문제다.

### ③ 토큰이 한 군데 더 생긴다

춘천 인스턴스가 `SKILL_TOKEN` 을 들고 있어야 우리 서버에 밀어넣을 수 있다.
비밀이 놓이는 자리가 하나 늘어난다. 관리 대상이 늘어난다는 뜻이다.

### ④ 개강 18일 전이다

새 인프라는 세우는 데 시간이 드는 게 아니라 **잘못 세웠을 때 시간이 든다.**
지금 필요한 최소 검증은 이 정도다.

```
1. 춘천 홈 리전으로 계정 생성          카드 확인 통과 여부
2. E2.1.Micro 1대 띄우기               용량 부족(Out of capacity) 흔함
3. 그 안에서 생협 API 200 나오는지      ← 이게 진짜 확인할 것
4. crawler/push.py 로 서버에 밀어넣기   토큰 왕복
5. cron 3회/일 걸고 이틀 지켜보기
```

★ 3번이 핵심이다. **춘천 IP 라고 반드시 되는 건 아니다.**
  생협이 IP 대역이 아니라 다른 기준으로 막고 있을 수도 있다.
  1~3번만 해보면 나머지가 값어치 있는지 알 수 있다 — 거기서 끊을 수 있다.

## 대안 (같이 놓고 봐야 공정하다)

```
집 PC + 작업 스케줄러    돈 0 · 오늘 됨          PC 가 꺼져 있으면 안 돈다
오라클 춘천              돈 0 · 반나절~하루      용량·카드·인수인계 위험
국내 VPS (카페24 등)     월 몇 천원 · 확실        총학 예산 집행 절차 필요
그대로 수동 백필         돈 0                    원칙 위반. 학기 중 반드시 잊는다
```

★ 어느 쪽을 골라도 **오늘 넣은 신선도 문안이 먼저다.**
  자동화를 시도하다 실패하면 개강 때 낡은 자료가 최신인 척 나간다.
  낡았다고 말해 두면 자동화가 늦어져도 틀린 답은 안 나간다.
